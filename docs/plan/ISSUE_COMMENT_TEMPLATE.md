# GitHub Issue Status Comment Template

Use this template for all issue status updates posted via GitHub CLI.

## Completed task template

Status update: Completed (YYYY-MM-DD)

## What was done
- Item 1
- Item 2

## Artifacts
- path/to/artifact-1
- path/to/artifact-2

## Decisions
- Decision 1
- Decision 2

## In-progress task template

Status update: In progress (YYYY-MM-DD)

## Current progress
- Progress item 1
- Progress item 2

## In-progress artifact
- path/to/in-progress-artifact

## Decisions made
- Decision 1
- Decision 2

## Next actions
1. Action 1
2. Action 2
3. Action 3

## Formatting rules
- Use real newlines, never escaped newline sequences.
- Use Markdown headings and flat bullet lists only.
- Keep each section concise and concrete.
- Include file paths for evidence.
